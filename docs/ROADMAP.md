# Roadmap

## Stage 0 — Documentation foundation

Complete: repository rules, source-of-truth documentation, starter folders, ignore rules, and environment examples.

## Stage 1 — Local application foundation (next)

Initialize Next.js and FastAPI; add health/connectivity checks, configuration validation, logging, CORS for local development, and basic tests. Do not implement trading features.

## Later stages

1. Database and identity foundation, including sole-admin enforcement.
2. Market-provider validation and server-side adapter.
3. Immutable trading, cash, holdings, and audit vertical slice.
4. Portfolio valuation and external-cash-flow-neutral return calculation.
5. Friends-only leaderboard and bounded admin controls.
6. Security hardening, tests, and deployment validation for Supabase, Render, and Cloudflare.
